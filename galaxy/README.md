# Static assets

Files here are served at the site root by Vite.

## stella.png — the mascot

Drop the star-photographer artwork here as `stella.png`, with a **transparent
background** (no checkerboard — that's just a transparency preview in editors),
ideally tightly cropped to the character, ~512×512 or larger.

The app loads it at `/stella.png`. If the file is missing, a simple drawn star
is shown instead, so nothing breaks.
